# tarefas-com-foco-IA

# PROMPT
Quero que a IA gere uma lista de tarefas para os empreendedores, com o objetivo de melhorar a organização de vendas. Considere o seguinte contexto: rotina de vendas diárias. O conteúdo deve ter formato de lista robusta (completa). Evite linguagem técnica.

# RESULTADO
📋 Lista de tarefas para rotina de vendas
Planejamento matinal: Reserve alguns minutos para revisar metas do dia e definir prioridades.

Organização de contatos: Atualize a lista de clientes e leads, separando quem precisa de retorno imediato.

Revisão de estoque: Verifique se os produtos disponíveis estão em quantidade suficiente e prontos para entrega.

Preparação de materiais: Tenha à mão catálogos, tabelas de preços ou amostras para facilitar a conversa com clientes.

Primeiros contatos: Faça ligações ou envie mensagens logo no início do dia para aumentar as chances de resposta.

Registro de interações: Anote cada conversa, pedido ou dúvida para não perder informações importantes.

Acompanhamento de propostas: Reforce contatos com clientes que já receberam ofertas, mostrando atenção e interesse.

Pausa estratégica: Tire pequenos intervalos para manter energia e foco durante o dia.

Revisão de metas: No meio do dia, confira se está no caminho certo para alcançar os objetivos.

Feedback dos clientes: Pergunte sobre a experiência de compra ou atendimento para identificar melhorias.

Organização financeira: Registre entradas e saídas de dinheiro para manter controle claro das vendas.

Encerramento do dia: Faça um resumo das conquistas, pendências e pontos de atenção para o próximo dia.

✏️Essa lista pode ajudar os empreendedores de forma prática porque transforma a rotina de vendas em um processo claro e organizado. Ao seguir cada etapa, o empreendedor evita esquecimentos, mantém o foco nas prioridades e garante que clientes recebam atenção constante. Além disso, o hábito de planejar, registrar e revisar cria disciplina e aumenta a produtividade, permitindo que as vendas sejam conduzidas com mais confiança e menos improviso.
